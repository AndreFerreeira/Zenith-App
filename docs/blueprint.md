# **App Name**: Zenith Mastery

## Core Features:

- Habit Tracker: Track daily habits and display progress.
- AI Assistant: Provides intelligent suggestions based on user data, like goal setting and time management. This is delivered through a tool that suggests personalized routines.
- Goal Setting: Set annual and weekly goals and monitor progress.
- Financial Overview: Display current balance and financial summaries.
- Weekly Planner: Plan the week with schedule functionality
- Monthly Strategy: A feature that provides strategy for the month

## Style Guidelines:

- Primary color: Deep Purple (#6750A4), chosen to give a modern yet calm feeling.
- Background color: Very dark desaturated purple (#1C1B1F), brightness adjusted for dark mode.
- Accent color: Violet (#D0BCFF) to complement and provide contrast with the primary color.
- Body and headline font: 'Inter' sans-serif for a clean and neutral look.
- Modern, minimalist icons to match the app's theme.
- Dark mode aesthetic with clear section separation for easy navigation.
- Subtle transitions for UI elements to create a smooth user experience.
